🌌 Cyberdeck Gesture Controller

Offline 3D Hand Hologram — Clean, Native, and 100% Lightweight

We pruned away all unnecessary Node.js packages and frontend compilations to make this project directory as lightweight as possible (under 1MB!). This ensures instant downloads, extraction, and clean execution on your local machine.

STEP 1

Install Camera & AI Libraries

Open your Terminal or Command Prompt and install these requirements:

pip install -r requirements.txt
STEP 2

Run Cyberdeck Controller

Boot up the main native gesture engine on your computer:

python cyberdeck.py
